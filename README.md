# Expense-Tracker-Web-Application
A responsive web application developed to help users record and manage their daily expenses.

# Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage
  
# Features
- Add daily expenses.
- View recorded expenses.
- Delete expense entries.
- Store expense records using Local Storage.
- Validate user inputs.
- Update the interface dynamically without page reloads.
  
# How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the HTML file in your web browser.

# Project Objective
Developed to gain practical experience in frontend web development, JavaScript programming and browser storage.
